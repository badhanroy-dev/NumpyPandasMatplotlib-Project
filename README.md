# Online Shopping Data Analysis

A small data analysis project using Python to explore online shopping orders, delivery times, customer ratings, and product categories.

## Tools Used
- Python
- NumPy
- Pandas
- Matplotlib

## Dataset
The dataset contains 20 unique orders with details such as order value, category, delivery time, customer rating, payment method, and order status.

It includes some missing values, duplicate records, and inconsistent data for cleaning practice.

## What I Did
- Loaded and explored the dataset using Pandas.
- Handled missing values and removed duplicate records.
- Corrected inconsistent categories and invalid ratings.
- Used NumPy for numerical calculations and statistics.
- Grouped, filtered, and sorted orders to analyze different aspects of the data.
- Created bar charts, histograms, and scatter plots using Matplotlib.
